# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues or pull requests.
Report them privately to the repository owner through GitHub and include:

- the affected component;
- reproduction steps;
- expected impact;
- a suggested mitigation, if known.

Do not include real credentials, personal data, or production data in a report.

## Supported versions

Until the first release, security fixes are applied to `develop` and promoted
to `main` through the normal reviewed release process.
